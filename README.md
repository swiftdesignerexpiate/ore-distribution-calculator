## 📖 About

Ore Distribution Calculator renders a real-time depth histogram of every ore type at your current position, updated as you move through the world.

---

## ✨ Features
<a name="features"></a>

- **Live Histogram** — updates every 2 seconds as you mine.
- **All Ore Types** — coal, iron, copper, gold, redstone, diamond, emerald, lapis, ancient debris.
- **Version Tables** — correct data for 1.16 through 1.21.
- **Peak Highlight** — marks the Y-level with highest yield per ore.
- **HUD Mode** — compact or expanded display.
- **Export** — save current histogram as PNG.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
